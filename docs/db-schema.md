# Database Schema

PostgreSQL, with the schema generated by Hibernate from the JPA entities in `entities/`.

```mermaid
erDiagram
    section ||--o{ topics : contains
    topics ||--o{ questions : has
    questions ||--o{ answers : has
    users ||--o{ attempt : makes
    topics ||--o{ attempt : "attempted via"
    attempt ||--o{ attempt_question : contains
    questions ||--o{ attempt_question : "asked in"
    users ||--o{ results : earns
    topics ||--o{ results : "scored on"

    users {
        uuid id PK
        varchar first_name
        varchar last_name
        varchar email
        varchar password
        smallint role
        boolean is_active
    }
    section {
        uuid id PK
        timestamptz created_at
        varchar name
        varchar description
        boolean is_active
    }
    topics {
        uuid id PK
        timestamptz created_at
        varchar name
        varchar description
        uuid section_id FK
        varchar topic_type
        int question_pool_size
        boolean is_active
        timestamp due_date
    }
    questions {
        uuid id PK
        timestamptz created_at
        uuid topic_id FK
        double points
        varchar question
        varchar answer
        varchar image_url
        boolean is_active
    }
    answers {
        uuid id PK
        timestamptz created_at
        uuid question_id FK
        varchar answer
        boolean is_correct
    }
    attempt {
        uuid id PK
        timestamptz created_at
        uuid topic_id FK
        uuid user_id FK
        double points_earned
        double total_points
        double percentage
        boolean is_finalized
    }
    attempt_question {
        uuid id PK
        timestamptz created_at
        uuid attempt_id FK
        uuid question_id FK
        boolean is_correct
        uuid submitted_answer_id
    }
    results {
        uuid id PK
        timestamptz created_at
        uuid user_id FK
        uuid topic_id FK
        double percentage
        double points_earned
        double total_points
    }
```

## Conventions

- All IDs are UUIDs generated by the application.
- `created_at` is set automatically on insert and never updated.
- `is_active` hides a record without deleting it.
- `percentage` is stored as a fraction from 0 to 1, not 0 to 100.
- `topic_type` is stored as text (`TEST`, `QUIZ`, `REVIEW`, `RANDOM_QUESTIONS`).
- `role` is stored as a number (`0` = STUDENT, `1` = ADMIN).
- `submitted_answer_id` is a plain UUID, not a foreign key.

## Deletion behavior

Deleting a section removes its topics, which removes their questions, which removes their answers (JPA cascade).
